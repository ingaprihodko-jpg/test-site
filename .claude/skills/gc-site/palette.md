# Цветовая схема

Схема по умолчанию для новых страниц. Снята с https://pariscreatorweek.com 02.11.2026 по вычисленным стилям страницы. Берём только цвета: шрифты и вёрстка того сайта не используются.

Если в ТЗ есть свои цвета или страница продолжает готовый проект со своей палитрой — приоритет у них.

## Токены

```css
.f5-root{
  /* тёмные секции */
  --f5-bg:#0E0818;            /* основной фон страницы */
  --f5-surface:#17102B;       /* карточки и панели на тёмном */
  --f5-bg-end:#2E1F55;        /* светлый конец тёмного градиента */
  --f5-on-dark:#FFFFFF;
  --f5-on-dark-soft:rgba(255,255,255,.72); /* второстепенный текст */
  --f5-line:rgba(195,188,234,.25);         /* рамки на тёмном, основа #C3BCEA */
  --f5-tint:rgba(204,197,246,.10);         /* заливка карточки на тёмном, основа #CCC5F6 */

  /* светлые секции */
  --f5-light:#FFFFFF;
  --f5-light-alt:#F5F5F5;
  --f5-ink:#1A1A1A;
  --f5-ink-soft:#555555;
  --f5-line-light:#DDDDDD;

  /* акценты */
  --f5-pink:#F0187A;
  --f5-raspberry:#E91E8C;
  --f5-violet:#9B3FD4;        /* единственный акцент для текста на светлом */
  --f5-indigo:#6B4DFF;
  --f5-blue:#5B6CF5;
  --f5-pink-soft:#FF5FA5;     /* крупные цифры на тёмном, в паре с #B478F0 */
  --f5-violet-soft:#B478F0;

  /* градиенты */
  --f5-grad-cta:linear-gradient(90deg,#F0187A,#6B4DFF);           /* главная кнопка */
  --f5-grad-text:linear-gradient(90deg,#F0187A,#8B35D6,#5B6CF5);  /* выделенное слово в заголовке */
  --f5-grad-num:linear-gradient(90deg,#FF5FA5,#B478F0);           /* крупные цифры */
  --f5-grad-panel:linear-gradient(135deg,#E91E8C,#9B3FD4,#3F51FF);/* яркая плашка */
  --f5-grad-strip:linear-gradient(90deg,#F0187A,#7B3FF5,#5B4DFF); /* узкая полоса */
  --f5-grad-footer:linear-gradient(#2E1F55,#0E0818);              /* подвал */
  --f5-glow:radial-gradient(rgba(155,63,212,.7) 0%,rgba(91,108,245,.3) 40%,rgba(0,0,0,0) 70%); /* подложка под иллюстрацию */
}
```

## Как применять

- Основа страницы тёмная `--f5-bg`. Светлые секции `--f5-light` и `--f5-light-alt` — для длинного текста и логотипов.
- Главная кнопка: `--f5-grad-cta`, белый жирный текст, скругление 999px. Вторая кнопка: белый фон, текст `#0E0818`. На светлых секциях вторая кнопка: фон `#0E0818`, белый текст.
- Градиентом выделять одно слово в заголовке, не весь заголовок и не абзацы.
- `--f5-glow` — готовая подложка, чтобы иллюстрация не висела в воздухе.
- Белый текст на чистом `#F0187A` контрастен только для крупного и жирного. Мелкий текст на акцент не ставить.
