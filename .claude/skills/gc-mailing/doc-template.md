# Формат документа с письмами (как пишет команда Life Practic)

Образец: «Цепочка для ОВ2 Сценарии» — https://docs.google.com/document/d/1btR5zImJMzyYm7va_-feRqFFkrIVEIXsm1HtPiR_pEQ

## Вкладки
- **«Емейл»** — письма для e-mail.
- **«Бот»** — те же сообщения для ботов/каналов (Telegram, ВКонтакте, MAX). Если внутри есть отдельный заголовок под канал («Сообщение в МАКС …») — этот текст только для этого канала.
Google Drive коннектор отдаёт все вкладки одним текстом, вкладки начинаются с заголовка `# Емейл`, `# Бот`.

## Как распознать письмо
Письмо начинается одним из вариантов:
- заголовок `### <название>` (триггерные письма: «Письмо спасибо после регистрации»);
- строка-шапка вида `DD/MM [Отправка в] HH:MM <назначение>. Сегмент: <описание словами>`
  (например: `10/10 Отправка в 10:00 Дожим на курс Сегмент: Все, кто регистрировался на ОВ1 + ОВ2 …`).

Внутри письма:
| Что в документе | Что это |
|---|---|
| `Тема:` | тема письма |
| `Прехедер:` | прехедер |
| `Для картинки` + 2–4 строки | текст для баннера (баннер делает дизайнер; в письмо этот текст НЕ идёт) |
| `баннер с отзывами`, `фото Е. Станковской` | пометка, какая картинка нужна |
| таблица с одной ячейкой (`\| Посмотреть программу \|`) или `\[Текст\]` | кнопка |
| несколько кнопок в одной ячейке / подряд строками в конце | блок кнопок |
| таблица с несколькими колонками | таблица в письме (тарифы, цены) |
| `{first_name}` | имя получателя → переменная GC из образца |
| `\[ссылка\]` | ссылку ещё не дали |
| **жирный**, *курсив*, списки `-` | сохранить как есть |

## Чего в документе обычно НЕТ (агент спрашивает или оставляет пустым)
- **Ссылок у кнопок** — их нужно получить у пользователя (UTM ставит пользователь).
- **Картинки баннера** — нужна готовая картинка (файл или ссылка из хранилища GC).
- **Сегмента по имени** — сегмент описан словами, агент его не выбирает.
- **Года** в дате — берётся текущий; если дата уже прошла — спросить.

## Комментарии
Комментарии редакторов («выделите визуально», «новое», предложения по тексту) — в письмо не идут.
Но правки-указания по оформлению («выделите визуально») — перечислить в отчёте, чтобы человек решил.
Текст по предложениям из комментариев НЕ переписывать.
