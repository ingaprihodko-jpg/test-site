Если у дашборда GC есть вкладка «Воронка» (`/pl/logic/funnel/update?id=…`), блоки правлю только в ней, а не через шестерёнку на вкладке «Панель».

**Why:** правка с Панели дала задвоение условий в блоках копии 1709223; пользователь указал редактировать через «Воронку».

**How to apply:** сначала проверить, есть ли вкладка «Воронка». Если есть — все фильтры менять там; после правок проверить каждый блок на задвоение. См. [[reference-gc-dashboard-bulk-edit]].
