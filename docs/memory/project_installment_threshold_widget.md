2026-11-03: в виджете GC 1675879 («Гений общения») сделаны 12 копий предложений с рассрочкой (8876846…8876863). HTML-элемент field89 (блок 2259596850) подменял id на копии при 5+ шт.; копии добавлены в промоакцию 511423. Код лежит в export/installment-threshold-widget.html, бэкап условий акции — в export/installment-threshold-promo-backup.txt.

**2026-11-12 всё убрано:** элемент field89 удалён из формы, копии убраны из акции 511423 (условия вернулись к бэкапу), все 12 копий стали «Неактуален». Причина: рассрочка/кредит GetCourse Pay (Всегда.Да, Покупай со Сбером) создаётся на сумму БЕЗ скидки по промокоду. Заказ 920894150 (Наталия Никитина) был на 34 750, а заявки на кредит ушли на 49 750. При оплате картой скидка сохраняется (заказ 919843324 оплачен на 34 750).

Кроме того, 5.11 в 09:31 у всех 12 основных предложений сняли «Ручную настройку способов оплаты» (с той же учётки, это была не я). Теперь у них общие настройки аккаунта, то есть рассрочка доступна при любой сумме, и скидка теряется так же.

**Why:** скидку промокода в рассрочку GC Pay не передаёт.
**How to apply:** рассрочку для предложений со скидкой по промокоду делать только через предложения, у которых сниженная цена стоит прямо в цене (6 950 за 5–9 шт., 5 950 за 10+), без промокода. Сначала проверить сумму на странице оплаты при выборе рассрочки, а не только getPrice.
