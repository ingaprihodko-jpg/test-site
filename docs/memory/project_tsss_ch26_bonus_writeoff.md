На tsss.site на ЧЧ26 начисляют бонусные рубли, 1 марта 2027 списать только остаток именно ЧЧ26 (у людей могут быть старые бонусы). GC не различает источники бонусов.

Решено (10.11.2026): **первыми тратятся бонусы ЧЧ26**. К списанию = max(0, начислено ЧЧ26 − оплачено бонусами с даты начисления).

- Метка при начислении: тег «ЧЧ26 бонусы» + доп. поле «ЧЧ26 начислено» (сумма).
- Оплаты бонусами видны в Платежах: фильтр «Тип платежа» = «Бонусный счет» (value VIRTUAL), брать статус «Получен».
- Скрипт export/tsss-ch26-bonus-writeoff.py: users + payments выгрузки → ch26-writeoff.csv, ch26-import.csv (поле «ЧЧ26 к списанию»), ch26-groups.txt (массовые списания по одинаковым суммам).

- Процесс-черновик GC 2640142 «[ЧЕРНОВИК] ЧЧ26 | Начисление бонусов + метка» (по пользователям): Начислить бонусные рубли → доп. поле «ЧЧ26 начислено» (id 23309785, Число) «Увеличить на» → группа «ЧЧ26 бонусы» → завершение. Сумма в обоих блоках пустая/0 — вписывает пользователь; одна копия процесса на одну сумму. Сегмент и запуск — пользователь сама, не запускать.
- Сумма в «Начислить бонусные рубли» — обычное поле, подстановка переменных не подтверждена.

- 11.11.2026: доп. поле «Бонусы до ЧЧ26» (id 23310744, Число) заполнено импортом у 1973 чел. с ненулевым бонусным балансом (снимок на 11.11, сумма ~13,1 млн).
- Журнал всех бонусных операций: /pl/sales/user-balance-row/ (дата, сумма, комментарий; фильтр «Пользователь» ищет и по email). Балансы: /pl/sales/user-balance/index (per-page=100 максимум; сортировка при одинаковых суммах нестабильна — дубли/пропуски).
- Импорт: /pl/user/user/import → «Ручной ввод», строки email;значение, вторая колонка автоматически ставится «дата регистрации» — переназначить на поле; галочки «перезаписать при совпадении эл. адреса» + «не добавлять без email». Карточки при массовом fetch иногда отдаются обрезанными — перезапрашивать.

- 11.11 сверка: у всех 1973 поле «Бонусы до ЧЧ26» = текущему балансу (движений после 10.11 16:30 не было).
- Быстрые источники: список пользователей с uc[rule_string]={"type":"user_virtualmoney","params":{"value":{"checker":"equal|gt","numval":"X"}}} — стабильная выдача с email (30/стр); значения доп. полей — POST /pl/user/user/get-user-additional-form-data?id=X, в ответе "23310744":значение ("23309785" = ЧЧ26 начислено); баланс+email — GET /pl/user/user/model?id=X (balances).
- НА ПАУЗЕ (11.11): Google-таблица проверки «было/ЧЧ26/потрачено/сгорит/останется/сверка». Скрипт-сборщик xlsx в scratchpad (build_ch26_sheet.py) — переложить в export/ при продолжении. Не решено: как вынести данные из браузера (cmd+c через расширение не попадает в системный буфер, navigator.clipboard завис).
- Несколько бонусных счетов в GC нельзя: только «Бонусный счет» и «Депозит» (депозит = реальные деньги, не использовать под подарки).

**Why:** операция списания в GC берёт фиксированную сумму, поэтому группируем людей по сумме.
**How to apply:** к 1 марта — выгрузить, прогнать скрипт, импортировать поле, списать по сегментам «поле = сумма». Не трогать процессы без согласования.
