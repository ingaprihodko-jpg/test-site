Редизайн первого экрана распродажи tsss (конференция 12 ноября 2026). Сайт на Tilda: web.tsss.site/birth, цвета #ffb036, #d25503, #2f2f2f.

- Файлы: tsss/sale-hero.html, tsss/assets/sale-mic.webp, export/sale-hero-embed.html (ASCII, сборка embed.py в scratchpad сессии), PNG в export/sale-hero-png.
- Черновая страница Tilda: pageid 352984709, проект TSSS, блок T123 с тремя вариантами. Вход в Tilda есть только в Chrome пользователя, не во встроенном браузере.

**Why:** клиент просил больше воздуха, игру со шрифтами, меньше микрофона; ленту анимируют бегущей строкой.
**How to apply:** T123 отверг код 120 КБ («слишком много текста»), 74 КБ прошёл; картинки лучше не держать в base64. Вставка: pbcopy + Cmd+V в ACE, сверка SHA-256 через ace.edit(...).getValue(). Предпросмотр Tilda не выполняет T123, нужна публикация; не публиковать без согласия. Несколько T123 на одной странице — у каждого свой id корня (ts-sale, ts-sale2), иначе скрипт второго блока работает с первым.
- Пользователь просит: каждую правку делать НОВЫМ вариантом, старые не трогать. Е = Г с белой кнопкой и скидкой-наклейкой, Ж = А; в обоих анимация кнопки (пульс + блик). Третий блок, корень ts-salevw. Гале нравятся А и Г, хотят A/B-тест на регистрацию.
- Четвёртый блок (корень ts-salezk): З = Е с выездом кнопки, К = Г с эквалайзером в кнопке; по одной анимации на вариант, кнопка в тёмном варианте белая (чтобы не путать со скидкой). И и Л удалены по просьбе. Лимит T123: 84 КБ сохранился.
- 2026-11-03: тёмная версия всего сайта на копии Tilda pageid 357751509 (web.tsss.site/page357751509.html, опубликована): в T123 record5451972701 первый экран Б (кнопка #popup:#regweb) + тёмная тема для нулевых блоков (JS по яркости цвета, скрыт фон спикеров 1750854256461/1750855764565, кнопки Group_744.svg подменены на оранжевую SVG). Файл export/birth-dark-embed.html, сборка scratchpad dark.py + theme.html, микрофон 700px q62 (83 КБ). Отдельно Ж кодом: export/sale-hero-zh.html.
- 2026-11-02: добавлены Г (Б + скидка на янтарной плашке) и Д (исходный макет, мельче шрифт, меньше микрофон) вторым блоком, страница опубликована: web.tsss.site/page352984709.html.
