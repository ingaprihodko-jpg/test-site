Модуль «Воронки» GC (бывш. ReFunnels): tsss.site/chtm/app/builder/v2, режимы Схема/План/Факт/Запуск.

- Шаблон «Создать по тренингу» — это мастер продажи курса (5 шагов: тренинг → предложение → группа → …), создаёт объекты в аккаунте; для аналитики прохождения не подходит.
- События для прохождения курса: «Заказ оплачен» (предложения ИЛИ любой из тегов — только OR, без AND), «Тренинг начат», «Тренинг завершен», «Урок посещен», «Новый ответ в уроке», «Событие в уроке».
- «Факт» не подтягивает историю: на 09.11.2026 «Заказ оплачен» с тегом «Продукт | Саунд-дизайн» за 2024–2026 показал 3 заказа при сотнях в GC. Данные копятся с момента создания блока. Состояния (заморозка, активен) событиями не выражаются — для них только дашборд с сегментами ([[gc-dashboard-bulk-edit]]).
- Период в «Факт» задаётся в URL: fds/fde (ISO UTC).
- Воронка «САУНД-ДИЗАЙН прохождение курса» = xT4MU2vGuoDA99fJaQs063058, пока один блок «Всего купили».
