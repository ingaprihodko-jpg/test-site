В рассылках GC обязательно переносить ВСЁ форматирование из ТЗ: жирный, курсив, подчёркивание. Таблицы из ТЗ оформлять красиво HTML-кодом (inline-стили). Макросы (переменные GC вроде `{first_name}` и им подобные) из ТЗ тоже надо ставить на место, не пропускать (просьба 07.11.2026, уточнить у пользователя какие именно, если встретится незнакомый).

**Why:** 07.11.2026 пользователь сказал «халтуришь и делаешь с ошибками много»: в письмах с 7 ноября я пропустила жирный (абзацы «Заголовок 3» в ТЗ: у Google Docs в HTML-выгрузке span без `font-weight:400` внутри h3 = ЖИРНЫЙ, старый парсер `gdoc_items.py` это не учитывал), подчёркивания и ещё собрала письма 9/14/17 ноября по устаревшей версии ТЗ.

**How to apply:** парсить ТЗ форматирующим парсером (`seven/fmt.py` в scratchpad той сессии: h* без явного font-weight:400 = bold, подчёркивание = text-decoration:underline). После сборки каждое письмо/бота сверять скриптом: из ТЗ и из черновика собрать строки жирного/курсива/подчёркивания (без пробелов) и сравнить LCS-диффом; плюс сверка полного текста. ТЗ могло обновиться с момента прошлой сборки — перед работой заново выгрузить и сравнить с копией, не считать старые черновики актуальными. См. [[feedback_stick_to_tz_copy]], [[project_gc_mailing_agent]].
