При вычитке текста клиента нельзя менять смысл, даже если видна явная несостыковка (пример: «Бить палкой по земле» при заголовке «по траве» в гайде «Гений общения» — пришлось вернуть).

**Why:** пользователь сказал «смысл не правь, верни назад».
**How to apply:** исправлять только опечатки, падежи, запятые, типографику; смысловые места — только упомянуть в отчёте, не менять. Связано с [[feedback-stick-to-tz-copy]].
