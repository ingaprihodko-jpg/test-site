F5GAME has a separate character-illustration set (a mascot guy, used across their funnels) hosted as static SVGs on another one of their GitHub Pages sites: `https://ingaprihodko-jpg.github.io/f5game-vibecoding/`. Known assets pulled from there so far:

- `robot.svg` → saved locally as `assets/images/robot-mascot.svg` (mascot hugging a robot — used in "technology" sections)
- `gift_real.svg` → saved locally as `assets/images/gift-mascot.svg` (mascot holding a wrapped gift box — used in gift/bonus sections)

**How to apply:** Before recreating a mascot illustration with SVG shapes or asking the user for a new asset, check `assets/images/` in this repo first, and if not there, ask whether it already exists on the `f5game-vibecoding` Pages site before assuming it needs to be generated from scratch.
