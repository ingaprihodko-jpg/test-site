When writing or editing on-page copy for any f5game-site landing page, use text strictly from the client's ТЗ (spec). Do not invent extra sentences, taglines, filler phrases, or "improve" the wording beyond what was literally provided.

**Why:** User's exact words: "не дописывай ничего лишнего, добавляй текст строго по тз" (don't add anything extra, add text strictly per the ТЗ) — said as a direct standing instruction, not about one specific fix.

**How to apply:** When a new section or block needs copy, pull it verbatim (or minimally restructured — e.g. splitting a sentence into a heading + subtitle, as already done for the program-card grid) from the ТЗ text the client supplied. If the ТЗ doesn't cover something (e.g. a UI label with no prescribed wording), keep it minimal and functional rather than inventing marketing copy — and if genuinely unsure what a block should say, ask rather than fill the gap with new writing.
