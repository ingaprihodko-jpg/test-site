На лендингах tsss.site (Олеся Григорьева, заказчик) повторяется одна и та же претензия: слишком большой пробел между блоками и разнобой в выравнивании заголовков секций (часть по центру, часть по левому краю). Пользователь попросила предотвращать это заранее (2026-10-27, МК «Персонажность», [[project-tsss-mk-personazhnost]]; раньше то же было на «Чтеце», [[project-tsss-chtec-page]]).

**Why:** клиент каждый раз возвращает правку «выровнять отступы и заголовки», это лишний круг.
**How to apply:** сразу при вёрстке: отступ секции на мобильном ~24px сверху/снизу (между блоками ~48px — 72px клиенту уже много), на десктопе ~56px; у h2 margin-top:0; отступ заголовок → контент ~28px моб / 40px деск; ВСЕ h2 секций — text-align:center (и кикеры под ними тоже по центру), без исключений по секциям. Перед сдачей пролистать мобильную версию и проверить стыки секций.
