Вставка кода через pbcopy → Cmd+V в редактор темы GC (cms/layout/update, вкладка CSS) использует буфер обмена пользователя. Между pbcopy и вставкой пользователь успел скопировать ссылку Tilda — я сохранил её вместо CSS, и тема «КЛУБ / Оформление уроков» (layout 102671 в INO) была пустой несколько минут.

**Why:** сохранение в тему сразу меняет вид всех уроков клуба у учеников, а сломанный CSS незаметен до проверки страницы.

**How to apply:** pbcopy и Cmd+V в одном пакете действий, сразу после вставки JS-проверка, что в редакторе есть маркер из файла (`MegaMamy`) и нет постороннего текста, и только потом «Сохранить»; после сохранения открыть вкладку CSS заново и сверить. Эталон CSS темы: export/mamamega-lesson-theme.css (в GC вставлять ASCII-версию без кириллицы, см. [[feedback_chrome_paste_cyrillic_bug]]). Правка CSS темы доходит до страниц с задержкой 1–3 минуты (кэш), не паниковать раньше.
