**Why:** без входа в GC адрес редактора 4599947 перекинул на /map_roles, и я по ошибке приняла страницу за «Карту ролей» — проверять страницу только после входа.
**How to apply:** правка элемента Redactor: клик в элемент → `$(ed).redactor('code.get'/'code.set')` → клик рядом с элементом (сохраняется на blur). Сам клик в элемент (инициализация Redactor) уже портит DOM: стирает содержимое нашего `<style>`, inline-стили, оборачивает img в figure — поэтому после клика НЕ брать code.get, а сразу code.set из эталона (сохранённая версия на сервере при этом цела) и не печатать с клавиатуры. code.set без фокуса не сохраняется. После сохранения сверять по перезагрузке. Скрипт таймера в элементе хранится с &lt;/&gt; уже давно — это не мы.
