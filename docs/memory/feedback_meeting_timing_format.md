Тайминг встречи по расшифровке Zoom (.vtt) оформлять так:
- время в формате чч:мм:сс (не мм:сс, не ч:мм);
- сначала ситуация/кейс, под ней разбираемые карты по порядку (конфликтоген, речевой оберег, техника, ролевое распределение, картина мира, удар юмора, фокус, алгоритм), у каждой таймкод; алгоритм не пропускать;
- для встреч с экспертным кабинетом отдельными пунктами «Знакомство с экспертным кабинетом» и «Личный кейс такой-то»;
- **всегда прикреплять чат Zoom**: рядом с записью лежит файл `…RecordingnewChat.txt`, его время идёт по тем же часам, что и таймкоды расшифровки; сообщения группировать по блокам встречи, текст сообщений не менять;
- выдавать простым текстом, который можно вставить (без таблиц), и дублировать файлом в Downloads.

**Why:** Инга вставляет тайминг и чат под видео встреч; в прошлые разы пропускали алгоритм и чат, пришлось просить добавить.

**How to apply:** при любой новой расшифровке из Downloads сразу искать парный файл чата `*RecordingnewChat.txt` и включать его в ответ.
