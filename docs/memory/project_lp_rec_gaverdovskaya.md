Страница с записью вебинара «Помощь за одну сессию без потери глубины» (ТЗ — Google Doc 1zgT2qtVvPC4qXB6L7gmqL2WE5v6nEbQIMh9J_TjR40E). Макеты lp-rec-a.html / lp-rec-b.html в корне, клиент выбрал B. 2026-11-03 перенесено на GC editor?id=4813210 (копия шаблона записи Станковской/Эрскина) **нативными блоками**, не одним HTML — так попросил пользователь.

- 2026-11-03: копия страницы 4813277 (ОП) потеряла стили — при копировании меняются ltBlock-id. Теперь стили на **CSS-классах блоков** (Стиль → «CSS-класс блока»): lp-gate, lp-hero, lp-timer, lp-video, lp-audio, lp-expert, lp-reviews, lp-course, lp-social-title, lp-social; селектор `:is(.lp-xxx,#f5x)` держит вес id. Для новой страницы: вставить CSS и проставить классы. Классы стоят на 4813210 и 4813277.
- Блоки (4813210): форма-вход ltBlock2260257509 (не трогать поля), первый экран …7512, таймер …260072 (новый, sticky, до 12.11.26 18:00), видео …7514, аудио …7515, эксперт …7513, отзывы HTML …259628 (export/lp-rec-reviews-gc.html), курс …7516, CSS-блок …7520 = старый CSS кнопок (2946 симв.) + export/lp-rec-gc.css после маркера «/* ===== Запись ОВ0 Гавердовская».
- Всплывающая форма удалена по просьбе («только форма-вход»).
- Блоки записи видны только группе (visibility[enabled]=group). На 2026-11-03 там стояла группа Станковской 4999080 — группы для Полины ещё не было, пользователь должен создать и поменять во всех блоках и в действии формы. Видео/аудио в блоках — тоже от Эрскина.
