Копия теста lifepractic-program-matcher (chatgpt.site) для распродажи Life Practic. Код: `export/lifepractic-matcher-embed.html`.

- Страница GC: editor?id=4779421 («распродажа - тест», публичный адрес /page3458), опубликована 2026-10-14.
- Блоки: b-652ea — HTML с тестом; b-33cb3 — скрытая служебная кнопка «Добавить в корзину» (без неё GC не грузит basket.js); b-1fe1e — форма (email, имя, доп. поле с плейсхолдером lpm_result), показывается ПЕРЕД результатами, результаты открываются после успешной отправки. «Пройти тест ещё раз» снова показывает форму (restoreForm), чтобы новая подборка перезаписала поле — так попросил пользователь.
- Доп. поле пользователя: «Распродажа_Подборка теста_результаты», customField-22372087, тип Строка — пишем только названия 5 программ (≤250 символов). Пользователь просил записывать ТОЛЬКО подборку, остальные ответы не нужны.
- Предложения и цены взяты со страницы распродажи «Летняя распродажа 2026 (для теста)» editor?id=4779420 (блоки b-5456c, b-4e0cc, b-02459…); цена в тесте = «Стоимость со скидкой от» (50% от цены предложения). Номера предложений вытаскиваются POST /pl/lite/block/settings?id=<blockId> (selected_id рядом с [action][position][offer_id]).
- Распродажа с этими предложениями — /_sale2026_copy (SALE_URL в коде, все ссылки data-sale-link). Корзина общая серверная для всех страниц домена — проверено: добавленное на одной странице видно на другой после ltCheckBasket(true).
- Шапка-hero скрывается во время теста; форма b-1fe1e стилизована CSS-ом #lpm-gate под тест.
- Без кода формы корзины GC сам открывает стандартную форму заказа (ltShowModalForm formCommon01), корзина общая серверная.

Обновление кода в GC: file_upload в созданный input[type=file] → SHA-256 сверка → панель «Настройки» HTML-блока → textarea «Значение» → реальные нажатия (пробел/Backspace) → «Сохранить и закрыть». См. [[feedback-getcourse-reveal-and-editor]].
